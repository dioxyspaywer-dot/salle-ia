📖 Comment ça marche

Les 3 IA. Archi planifie, Dev écrit le code (en fichiers séparés index.html, style.css, script.js), Critique cherche les défauts. Sous chaque nom tu vois quel modèle répond vraiment.

💬 Discussion. Tu écris ou tu parles (🎤), chaque IA répond. Touche @Dev, @Archi ou @Critique pour n’interroger qu’une seule IA.

🛠️ Travail. Tu donnes un brief : les IA s’enchaînent seules jusqu’à ce que Critique dise VALIDÉ, ou jusqu’au maximum de tours. Bouton Stop pour arrêter.

⚖️ Décision. Chaque IA donne son avis, puis Archi tranche et t’envoie la réponse finale (bloc bleu « Décision de l’équipe »).

💻 Code. Touche le nom d’un fichier pour copier son nom, « Copier le code » pour copier son contenu, puis colle dans ton dépôt GitHub. 👁️ Aperçu montre la page.

🔊 Écouter. Sous chaque réponse, touche 🔊 pour que l’IA la lise à voix haute. 📎 Image. Joins une photo à ton message : elle est envoyée aux IA (Gemini sait la lire ; un modèle OpenRouter doit accepter les images).

✂️ Séparation automatique. Si une IA met le CSS ou le JavaScript dans la page HTML, l’application les sépare toute seule en style.css et script.js et les relie. Ces fichiers portent un ✂️ dans la salle.

👁️ Aperçu. Les fichiers restent séparés dans l’onglet Code ; seul l’aperçu les assemble. Plusieurs pages HTML : touche un lien pour passer d’une page à l’autre, ou choisis la page dans la liste. React (fichier .jsx) marche avec internet. Un fichier Python (.py) apparaît dans la liste avec ▶ : touche-le pour l’exécuter et voir son résultat (premier chargement lourd, environ 10 Mo). 🧹 efface les données de l’aperçu (faux panier, faux comptes). Un vrai serveur (Node, PHP) ne peut pas tourner dans un téléphone : l’IA simule alors le backend en JavaScript.

Combiner les IA. Ci-dessus, choisis pour chaque IA le fournisseur et le modèle, ou désactive-la. Sans clé OpenRouter, Dev utilise Gemini (indiqué « remplaçant »).

Tes clés restent dans ce téléphone.
